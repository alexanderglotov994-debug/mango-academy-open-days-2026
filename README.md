# Манго Академия — территория суперсил

Демонстрационный сайт дней открытых дверей 16–18 декабря 2026 года.

Сайт: https://alexanderglotov994-debug.github.io/mango-academy-open-days-2026/

## Просмотр

- `index.html` — внешняя хронология с выбором дня с 30 ноября по 21 декабря, только рабочие дни пятидневной недели.
- `site.html?day=2026-12-16` — сайт без внешней хронологии.
- `film.html` — HTML-ролик с программной анимацией и встроенной аудиодорожкой, 99 секунд.

Сборка не нужна. Для локального просмотра: `python -m http.server 8000`, затем `http://localhost:8000`. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает Jekyll.

## Сценарии по датам

- 30 ноября: тизер.
- 1–8 декабря: шесть вопросов «Досье Академии»; новые вопросы 1, 2, 3, 4, 7 и 8 декабря.
- 9–18 декабря: три подвкладки — ролик об Академии, команды с формой обращения, расписание с семью вопросами диагностики Marvel.
- «Полезные вопросы» показываются только 13–18 декабря.
- С 19 декабря: раздел материалов и обращения к командам. Дополнительного квиза нет.

## Редактирование

- `app.js`: команды, демо-контакты (`config`), ежедневные вопросы, диагностика, формы и переходы.
- `data.js`: программа встреч.
- `style.css`: дизайн сайта в цветах предоставленного логотипа.
- `film.html`, `film.css`, `film.js`: семь программно анимированных сцен и плеер.
- `film-timings.js`: тайминги сцен и слов, привязанные к аудиодорожке.
- `assets/audio/script.txt`: полный текст озвучки.
- `assets/audio/academy.mp3`: Microsoft Edge TTS, `ru-RU-SvetlanaNeural`, темп `+10%`, как в референсном ролике. HeyGen и говорящий аватар не используются.
- `assets/audio/timings.json`: исходные временные границы слов и сцен.
- `assets/ma-logo-yellow.png`: предоставленный пользователем логотип без изменений.
- `assets/team-demo.png`: сгенерированные демонстрационные портреты; не реальные сотрудники.
- `assets/heroes.svg`: программно нарисованные супергеройские эмблемы.

GSAP и шрифт сохранены локально. Для работы опубликованного сайта внешние API генерации не нужны. Звук запускается только по нажатию пользователя; доступны пауза, повтор, перемотка, субтитры и финальные действия. При переходе в другую вкладку сайта ролик приостанавливается.

## Демонстрационные данные

Числа викторины — учебные примеры, а не отчётность компании. Имена руководителей, контакты, адрес портала, расписание и материалы требуют согласования. Три направления Академии и основные темы развития указаны по пользовательскому описанию.

Ответы ежедневной викторины сохраняются только в localStorage браузера. Общего сбора ответов нет. Диагностика подбирает встречи по интересам и не оценивает личность.

Форма подготавливает `mailto:academy@example.com` с темой и текстом. Это демонстрационный адрес; пользователь самостоятельно выбирает получателя и отправляет письмо в почтовой программе. Ссылка на учебный портал ведёт на `https://example.com` и предваряется пояснением о заглушке. События календаря помечены как предварительные.
