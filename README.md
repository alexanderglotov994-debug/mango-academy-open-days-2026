# Манго Академия — дни открытых дверей

Интерактивная концепция мероприятия 16–18 декабря 2026 года.

**Сайт:** https://alexanderglotov994-debug.github.io/mango-academy-open-days-2026/

`index.html` — сайт с внешней хронологией: выберите день с 30 ноября по 19 декабря, чтобы посмотреть соответствующий этап.

`site.html?day=2026-12-09` — только страница сайта без внешней хронологии. Параметр `day` задаёт дату просмотра; по умолчанию выбрано 9 декабря.

Этапы: тизер, шесть заданий новогоднего квиза, программа и подбор встреч, дни мероприятия, итоги и материалы.

## Запуск и публикация

Сборка и установка зависимостей не нужны. Для локального просмотра запустите `python -m http.server 8000` из папки проекта и откройте `http://localhost:8000`.

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Все изображения находятся в `assets`, внешние библиотеки и шрифты не используются.

## Что редактировать

- `app.js`: тексты, задания, расписание и логика интерактивных блоков.
- `style.css`: оформление и адаптивная вёрстка.
- `index.html`: внешняя хронология и оболочка просмотра.
- `assets/portal.svg`: главная иллюстрация.

## Ограничения текущей версии

Это проект наполнения: темы, время, ведущие и материалы требуют согласования. Реальные ссылки на встречи и записи не добавлены.

Ответы квиза сохраняются только в localStorage браузера и не отправляются организаторам. GitHub Pages размещает статические файлы; общее хранение ответов требует отдельного сервиса. Форма запроса скачивает текстовый файл. События календаря помечены как предварительные.
